# EDA Pipeline

Репозиторий содержит сценарий EDA для задачи детекции фразы «не слышу/не слышно» в аудио.

## Быстрый старт
- `!git clone <repo>`
- `%cd <repo>`
- `!pip install -r EDA/requirements.txt`
- `!python EDA/run.py all`

## Каталоги
- `configs/` — YAML конфигурации запуска.
- `templates/` — шаблоны отчётов (пока пусто).
- `scripts/` — вспомогательные скрипты/тесты.
- `docs/` — документация и чек-листы.
- `notebooks/` — черновые ноутбуки.
